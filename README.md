# stitchglob

Stitch identifiers and glob tokens for idempotent workflows.

**Site:** https://theworker02.github.io/stitchglob/

## Install / run

```bash
git clone https://github.com/theworker02/stitchglob.git
cd stitchglob
node src/cli.js
node --test
```
